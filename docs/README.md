# Documentation for The Chat Place

This folder contains user-facing documentation for The Chat Place.

## User Guide

The main user guide for new and experienced users of The Chat Place.

- **USER_GUIDE.md** — The primary user guide in Markdown format (easy to edit)
- **USER_GUIDE.html** — The same guide as a styled HTML page for publishing

Both files are kept in sync. Edit `USER_GUIDE.md` first; when you're ready to publish, update the HTML version accordingly. They cover:

1. **What is The Chat Place?** — Purpose, key features, why you'd use it
2. **Getting started** — Installation and first launch
3. **Common workflows** — Finding sessions, reading messages, replying, approving permissions
4. **Organizing with groups** — How groups work and why they matter
5. **Working with code** — Viewing changes, copying code blocks
6. **Your own sessions** — Creating sessions, permission modes, continuing desktop sessions
7. **Settings and preferences** — Announcements, reading, attachments, Remote Control
8. **Understanding the status bar** — What the status bar shows and how to navigate it
9. **Advanced features** — Export, code blocks, context usage, repeating announcements
10. **Tips and tricks** — Keyboard navigation, filtering, queued messages
11. **Getting help** — Shortcuts, settings, reporting bugs, signing in
12. **What's unique about The Chat Place** — Read-only sessions, local storage, independence
13. **Troubleshooting** — Common issues and how to fix them

### For web publishing

The HTML file (`USER_GUIDE.html`) includes:
- Light and dark mode support (respects `prefers-color-scheme`)
- Accessible typography and color contrast
- A table of contents that links to each section
- Semantic HTML for screen readers
- Mobile-friendly responsive layout

To publish:
1. Upload `USER_GUIDE.html` to your web server
2. Link to it from the main README, release notes, or website
3. Update the HTML if the Markdown changes significantly

## Keyboard Shortcuts Reference

The keyboard shortcuts are documented in multiple formats:

- **In the app:** Press F1 to see the full list (Help → Keyboard Shortcuts)
- **../keyboard-shortcuts.md** — Markdown version (generated by the app from `thechatplace/ui_text.py`)
- **../keyboard-shortcuts.html** — HTML version
- **../keyboard-shortcuts.txt** — Plain text version

These are auto-generated from the app's `SHORTCUTS` list in `thechatplace/ui_text.py` and are identical to what F1 shows.

## Feature Requests

**FEATURE_REQUESTS.md** — Identifies potential improvements to the app based on the codebase and user guide analysis.

This document:
- Lists features that could enhance user experience
- Explains the current state and user impact for each
- Suggests improvements and relevant code files
- Distinguishes between bugs, feature requests, and known limitations

This can be used as a reference when prioritizing work or responding to user feedback.

## Maintaining these docs

1. **When you change app functionality:** Update USER_GUIDE.md first
2. **When releasing:** Update the HTML version if needed, ensure links are current
3. **When new keyboard shortcuts are added:** They update automatically in the app; regenerate the keyboard-shortcuts files if needed
4. **When updating release notes:** Link to the USER_GUIDE.html for new users
