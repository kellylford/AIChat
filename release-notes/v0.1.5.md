# The Chat Place 0.1.5

An update to 0.1.4, still a pre-release. If you have 0.1.4 installed, it offers this update itself
(Help, Check for Updates asks at once), and your sessions and settings are kept.

## Fixed

- **Claude carries on after background commands.** When Claude starts a command in the
  background, such as a build or a wait for GitHub checks, and then answers, the command used to
  be stopped as soon as the answer came, and Claude never picked it up again. Now the session keeps running:
  you hear the answer and what is still running, and when the work finishes Claude carries on by
  itself and its next answer is announced. While it waits, a message you send goes to Claude at
  once instead of being queued. Turn Status (Ctrl+Shift+T) names the work still running, and Stop
  ends it. After a helper agent finishes, Claude's answer to it is now said too, where before
  nothing was. (#161, #167)
- **Claude Code's sign-in is read even when it adds a notice.** Some installs of Claude Code, such
  as one installed with npm, print a notice along with their sign-in status. The Chat Place then
  said it "Couldn't tell whether Claude Code is signed in" and that Claude Code "said {". It now
  reads the status and ignores the notice. If an answer still can't be read, Help, Claude Code
  Sign-in says so and suggests running claude auth status in a terminal to see it. (#157)

## Added

- **New Session remembers your folders, clones from GitHub, and can work on a branch of its
  own.** In File, New Session (Ctrl+N), the Folder box now starts at the folder you used most
  recently, and Up and Down Arrow move through every folder your sessions have used, newest
  first. **From GitHub** (Alt+G) lists your GitHub repositories: type to narrow the list, or type
  owner/name for any repository, and press Enter. If it isn't in your GitHub folder yet, it's
  cloned there first. **Work in** (Alt+I) can now be **A new worktree**: choose a branch, or type
  a new branch name, and the session works in its own copy of the repository on that branch,
  leaving your folder as it is. From GitHub needs the GitHub CLI (gh), signed in. (#154, #156)
- **Sessions you start in a terminal are listed.** If you run Claude Code by typing claude in a
  terminal, those sessions now appear in the session list alongside the desktop app's, each
  saying "terminal session" and naming its folder. Its title is the name you gave it with
  /rename, or else the one Claude Code gave it, or else the start of your first message. Enter
  reads the conversation. The list shows when one is working or waiting on you in the
  terminal, and announces it. They're read-only here: reply in the terminal, or carry one on in
  The Chat Place with Continue Here (Ctrl+Shift+N). View, Show Sessions, Terminal Sessions
  (Alt+V, H, T) lists only them. Sessions that scripts run with claude -p aren't listed. (#158, #159)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you
exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs
   access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to
   [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

The same files as 0.1.4: TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and
TheChatPlace-macos-arm64.dmg, with the update feeds. See the
[user guide](https://github.com/kellylford/AIChat/blob/main/docs/user-guide.md) to get started, and
the [README](https://github.com/kellylford/AIChat#readme) for everything The Chat Place does.

## Requirements

The same as 0.1.0: Windows 10 or 11, or a Mac with Apple silicon, and Claude Code installed with
its native installer and signed in to a Claude subscription. See the 0.1.0 release notes for the
details.
