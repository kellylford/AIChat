# The Chat Place 0.1.3

An update to 0.1.2, still a pre-release. If you have 0.1.2 installed, it offers this update itself
(Help, Check for Updates asks at once), and your sessions and settings are kept.

## Fixed

- **New Session describes the permission modes correctly.** Accept edits and Manual said that
  anything needing approval was refused. In fact Claude asks you, and Ctrl+Shift+A answers. (#104)
- **On a Mac, the arrow keys choose an answer when Claude asks a question.** In the dialog that
  Cmd+Shift+A opens, Up and Down (or Left and Right) did nothing in a question's options, so only
  the first could be reached by keyboard. They now move through the options and choose each one,
  as on Windows, and wrap around at the ends. (#121)
- **On a Mac, Return presses the focused button in the main window.** Return on Send, Stop,
  Commands, Attach Files and the other buttons did nothing; only Space pressed them. Now either
  key does, as on Windows. (#125)
- **On a Mac, VO+Shift+M opens the context menu in the session list and the messages list.** It
  did nothing, so with VoiceOver the session's menu and a message's menu (Read Full Message, Code
  Blocks and the rest) couldn't be reached that way. It now opens the same menu as the
  Applications key on Windows, for the selected row. (#128)
- **Right-clicking a message opens the menu for that message.** The menu was for whichever
  message was highlighted, so Copy Message or Read Full Message could act on a different one. Now
  the message you right-click is selected first, as in the session list. (#129)
- **Help, Claude Code Sign-in says what's wrong when it can't tell.** It said only "Couldn't tell
  whether Claude Code is signed in". Now it says why: Claude Code isn't installed or can't be
  found, it's too old to ask (`claude update` fixes that), it didn't answer, or what it printed.
- **Claude Code is found in more places.** On a Mac, a Claude Code installed with Homebrew is
  now found; an app started from the Finder doesn't see your terminal's PATH, so it was missed.
  On Windows, a newer npm install of Claude Code is now used, since it runs the same native
  program as the installer's.
- **On a Mac, signing in opens a Terminal window.** Help, Claude Code Sign-in started the sign-in
  with no window to see or answer it. It now runs in Terminal, and The Chat Place says the result
  once you've signed in.

## Added

- **Installing Claude Code from The Chat Place.** If Claude Code isn't installed, The Chat Place
  says so at start-up, and Help, Claude Code Sign-in gives the install command for your computer
  and offers to run Claude Code's own installer in a window of its own. When it's finished, The
  Chat Place checks again and offers to sign you in. The user guide's "Before you start" has the
  install commands too.
- **Your sessions on other computers.** File, Other Machines (Ctrl+Shift+M) sends a message to a
  Claude Code session on another of your computers, and you hear its reply here, without going
  to that computer. It goes through Claude in one of your Chat Place sessions with Remote Control
  on: Refresh the list asks Claude which sessions there are, then you choose one, type, and press
  Enter. The other computer's own conversation can't be read from here, only what it sends back.
  The user guide's new section, "Your sessions on other computers", explains it. (#123)
- **Messages from other sessions are shown and announced.** A message another Claude Code
  session sends to one of yours now shows as "From" and that session's name, and it's announced.
  Before, one that arrived while Claude was working didn't show at all, and one that started a
  turn looked like something you'd typed. A Chat Place session also keeps the same name every
  turn now, so other sessions can keep reaching it. (#123)
- **A user guide**, under Help, User Guide (Alt+H, G). It starts with the everyday things, such as
  reading a session, replying and answering Claude, and goes on to groups, announcements and the
  rest. It opens as a page you can move through by heading, or as plain text (Alt+P), and works
  offline. It's also on the web at https://kellylford.github.io/AIChat/user-guide.html, with a
  Contents list, alongside the keyboard shortcuts. (#102, #104)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you
exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs
   access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to
   [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

The same files as 0.1.2: TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and
TheChatPlace-macos-arm64.dmg, with the update feeds. See the
[user guide](https://github.com/kellylford/AIChat/blob/main/docs/user-guide.md) to get started, and
the [README](https://github.com/kellylford/AIChat#readme) for everything The Chat Place does.

## Requirements

The same as 0.1.0: Windows 10 or 11, or a Mac with Apple silicon, and Claude Code installed with
its native installer and signed in to a Claude subscription. See the 0.1.0 release notes for the
details.
