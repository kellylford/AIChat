# The Chat Place 0.1.1

A small update to 0.1.0, still a pre-release. If you have 0.1.0 installed, it offers this update
itself (Help, Check for Updates asks at once), and your sessions and settings are kept.

## What's new

- **A File menu.** The first menu is now File, so Alt+F opens it as in other Windows programs.
  Everything that was on the Session menu is there. Attach Files in the reply area moves to
  Alt+T; Ctrl+Shift+F still attaches files from anywhere.
- **Hide a session instead of losing it.** File, Hide Session (or the Delete key in the session
  list) takes any session out of the list, a Claude desktop app session too, without changing it.
  View, Show Sessions, Hidden lists what you've hidden, and File, Bring Back Session returns one.
  Hidden sessions stay quiet: they aren't announced, notified or counted as needing you.
- **Delete a session for good.** For a chat you started in The Chat Place and have hidden, File,
  Delete Session Permanently deletes it and its conversation from your PC, after asking. This
  replaces Forget, which couldn't be undone and left you no way back.
- **On the Mac, VoiceOver reads more.** Edit boxes, lists and choices now have their names,
  VO+M finds The Chat Place's own menus, speech falls back to the system voice when VoiceOver
  won't speak for it, and the reply box is taller and keeps its width.
- **An icon.** The Chat Place now has its own icon, a speech bubble, on the program, the
  installer, the Start menu, the window and the notification area.

## Downloads

The same files as 0.1.0: TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and
TheChatPlace-macos-arm64.dmg, with the update feeds. See the
[README](https://github.com/kellylford/AIChat#readme) for everything The Chat Place does.

## Requirements

The same as 0.1.0: Windows 10 or 11, or a Mac with Apple silicon, and Claude Code installed with
its native installer and signed in to a Claude subscription. See the 0.1.0 release notes for the
details.
