# The Chat Place 0.1.2

A small update to 0.1.1, still a pre-release. If you have 0.1.1 installed, it offers this update
itself (Help, Check for Updates asks at once), and your sessions and settings are kept.

## Added

- **Rename a session** with F2, File, Rename Session, or the session's menu. A chat you started
  in The Chat Place is renamed outright. A Claude desktop app session's new name shows only in The
  Chat Place, because the desktop app's files are never changed; clear the name to go back to the
  desktop app's. (#93, #97)
- **A menu for each session.** The Applications key or Shift+F10 in the session list, or a
  right-click, opens the selected session's commands: load, open in Claude, continue here,
  rename, Remote Control, groups, export, and hide or delete. (#89, #97)
- **What Claude knows about you** (Ctrl+Shift+K, or View, What Claude Knows About You). Claude
  Code keeps what it knows about you in plain files, and this lists them by kind: your
  instructions (CLAUDE.md, yours and each project's), the memories Claude saved, your skills,
  subagents, slash commands, output styles and settings. Enter reads one, and Edit in Your Editor
  opens it in your own editor. The Chat Place itself never changes them. (#92, #97)
- **Ctrl+Shift+B opens a message's code blocks** straight from the messages list, to list, read
  and copy each one; before, they were only on the message's menu. (#101)
- **Remote Control is easier to find.** It's on each session's menu, a session on Remote Control
  says so in its row and heading, and View, Show Sessions, Remote Control Sessions now lists your
  Chat Place sessions too. For a Claude desktop app session, File, Remote Control offers to open
  it in the desktop app, where its Remote Control is turned on, or to continue it here as a copy
  with Remote Control on from its first turn. (#96, #99)

## Changed

- **Deleting a session for good is one step.** In 0.1.1 you had to hide a chat, switch to the
  Hidden view, find it again and then delete it, and nothing told you so. Now File, Delete Session
  Permanently, or **Shift+Delete** in the session list, works on any chat you started in The Chat
  Place, from any view. It still asks first, with No as the answer if you just press Enter. Claude
  desktop app sessions can still only be hidden; delete those in the desktop app. (#90)
- **The menu says which key does what.** File, Hide Session reads as "Hide Session (Delete)" and
  Delete Session Permanently as "Delete Session Permanently (Shift+Delete)", so screen readers
  read the key along with the command. (#90)
- **The keyboard shortcuts are online too:** every key, as a web page, Markdown and plain text, in
  the [docs folder](https://github.com/kellylford/AIChat/tree/main/docs), made from the same list
  as Help, Keyboard Shortcuts. (#88)

## Fixed

- **Coming back to The Chat Place with a dialog open works.** With Code Blocks or another
  dialog open (a message box or a dialog over a dialog included), switching to another app and
  back could leave focus on the main window behind the dialog, where no key did anything, so the
  app seemed hung. The dialog now comes forward with
  focus where you left it. (#103)
- **Shift+F10 in the session list no longer flashes the File menu.** Focus went to the menu bar
  for a moment, and a screen reader said so, before anything else happened. Shift+F10 and the
  Applications key now open the session's menu straight away, in the session list and the
  messages. (#89, #97)
- **Delete in the attachments list removes the attachment again.** It hid the whole loaded
  session instead, without asking, and left the file attached. (#90)
- **Deleting the chat you have open deletes its conversation every time.** On Windows it could
  fail now and then, because The Chat Place was still reading it. (#90)
- **After a delete, a screen reader reads the session that took its place**, not the one that was
  just deleted. (#90)
- **A failed delete says so.** If a chat's files can't be deleted, you're told they're still on
  your computer, rather than hearing that it was deleted. (#90)
- **A deleted chat's unsent reply no longer lingers.** It made The Chat Place warn about unsent
  text you couldn't reach, and held back automatic updates. (#90)
- **Safer deletes.** Delete Session Permanently waits while a chat is working, here or in a
  terminal, and refuses any chat whose id belongs to a Claude desktop app session, so it can never
  delete one of the desktop app's conversations. (#90)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you
exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs
   access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to
   [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

The same files as 0.1.1: TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and
TheChatPlace-macos-arm64.dmg, with the update feeds. See the
[README](https://github.com/kellylford/AIChat#readme) for everything The Chat Place does.

## Requirements

The same as 0.1.0: Windows 10 or 11, or a Mac with Apple silicon, and Claude Code installed with
its native installer and signed in to a Claude subscription. See the 0.1.0 release notes for the
details.
